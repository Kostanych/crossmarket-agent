# Роутинг A+C: какой тул выбирает оркестратор

Сгенерировано `python -m evals routing` 2026-09-05. Файл перезаписывается каждым прогоном — история в git.

Accuracy роутинга — доля однохоповых вопросов, где первым вызванным тулом оказался размеченный. Вызовы скилла из последовательности вычищены. Мультихоповые кейсы в метрику не входят: правильных вызовов там два, и порядок между ними вопросом не задан.
