# Матчинг ВБ↔Озон: модель подтверждения на размеченных парах

Сгенерировано `python -m evals matching` 2026-09-07. Файл перезаписывается каждым прогоном — история в git.

Вырожденный режим — прямая метрика плана: precision / recall / F1 против меток пар. Отчётная цифра берётся со строки среднего по тест-сплиту: у метрики есть разброс от прогона к прогону при неизменных промпте и данных. Полный режим меряет весь путь карточка ВБ → кандидаты → подтверждение; исход «аналога нет» считается по тем же вердиктам, выбрасывая из кандидатов размеченного партнёра. Подтверждённые не-партнёры в ошибку автоматически не пишутся — истины по ним нет, они читаются глазами.
