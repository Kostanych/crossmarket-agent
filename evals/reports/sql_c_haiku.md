# Tool C: text2sql к снапшоту ClickHouse

Сгенерировано `python -m evals sql` 2026-09-09. Файл перезаписывается каждым прогоном — история в git.

Ответ засчитан, если строки хотя бы одного исполнившегося запроса агента совпали со строками эталонного SQL кейса после нормализации: округление чисел, порядок строк у неупорядоченных вопросов, перестановка и лишние колонки. `exact_match` — совпадение без послаблений по форме, `answer_match` — названы ли эталонные значения в самом тексте ответа.
